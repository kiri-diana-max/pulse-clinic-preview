# Пульс клиники — клиентский макет

Обновлено 9 ноября 2026: три адаптивных экрана, авторский бренд DIANA TEPLOVA / Teploff Digital и ссылки на связанные сервисы.

- `index.html` — стартовая страница.
- `demo.html` — исходный демонстрационный кабинет с вымышленными данными.
- `mobile-preview.html` — просмотр в узкой рамке.
- `assets/` — иллюстрации и предоставленный авторский логотип.

Макет опубликован на GitHub Pages. Вход ведёт на действующий сайт пульс-клиники.рф, где уже работает серверная авторизация по логину и паролю. Макет не хранит учётные данные и не обращается к базе клиник.

Действующий сервер, два клиента, их кабинеты и доступы не изменены. Ссылки на Мой сахар, Мой онкоскрининг и Мою колоноскопию объединяют проекты на уровне витрины; базы данных и аккаунты остаются в своих сервисах.

Локальный просмотр: `python3 -m http.server 8765`.
