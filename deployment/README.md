# Опубликованная главная REG.RU

`index.html` — точная копия главной пульс-клиники.рф от 9 ноября 2026. Она использует `style.css`, `script.js` и `assets/` из корня этого репозитория, размещённые на хостинге в `/pulse-landing-20261109/`. Демо из `demo.html` опубликовано как `/pulse-demo.html`.

Основной текст увеличен для компьютеров и телефонов; изображение приближено к тексту первого экрана. Сохранены три экрана, анимация пульса, демонстрация кабинета и ссылки на связанные приложения.

Существующий кабинет `/cabinet.html`, серверный API и данные двух клиентов при публикации главной не заменяются.

Исходники остальных приложений: [Мой сахар](https://github.com/kiri-diana-max/moy-sahar/tree/main/reg-ru), [Мой онкоскрининг](https://github.com/kiri-diana-max/moy-oncoscreen), [Моя колоноскопия](https://github.com/kiri-diana-max/moya-colonoscopy).
